# Приглашение Миши и Полины

Статический сайт-приглашение и печатная карточка.

## Файлы

- `index.html` — основная страница.
- `print.html` — макет бумажного приглашения.
- `styles.css` — визуальная система.
- `script.js` — персонализация имени, play-кнопка, MIDI-анимация и подключение анкеты.
- `assets/` — фотографии, SVG и аудиотрек.

## Шрифты

Имена `Misha` и `Polina` на первом экране набраны локальным шрифтом Scorpius:
`assets/scorpius.otf`.

## Музыка

Трек лежит в `assets/zuki.mp3`. Кнопка `Play` на первом экране запускает аудио.
При первом запуске hero-секция получает класс `is-midi-active`, а `is-playing`
только включает движение. Поэтому при паузе MIDI-дорожка замирает на текущем
кадре.

## Персональная ссылка

Имя можно подставить через параметр:

```text
index.html?name=Аня
print.html?name=Аня
```

## Анкета

Самый удобный вариант без backend — Google Forms или Яндекс Форма с ответами в таблицу.
После создания формы вставьте ссылку в `EXTERNAL_FORM_URL` в `script.js`.

Если появится endpoint для приема JSON, вставьте его в `RSVP_ENDPOINT`.

Пока обе настройки пустые, форма работает в тестовом режиме: ответ сохраняется
в `localStorage` браузера под ключом `misha-polina-rsvp-test-submissions` и
копируется в буфер обмена.

## Игра

Экран `#game` содержит canvas-мини-игру без внешних библиотек: Миша идёт к
Полине через Ableton-подобную сетку, собирает свадебные предметы, перепрыгивает
опасные клипы и waveform-блоки, а в финале встречает Полину и Юми. Управление:
стрелки влево-вправо для движения, пробел/стрелка вверх/тап для прыжка. У
игрока три жизни, короткие чекпойнты и безопасный stomp по waveform-блокам.
