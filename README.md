# Заглушка сайта «Миша и Полина»

Это простая статичная версия сайта-приглашения.

## Что внутри

- `index.html` — структура страницы и тексты.
- `style.css` — цвета, блоки, мобильная версия.
- `script.js` — мобильное меню.
- `assets/` — папка для будущих фото и картинок.

## Как быстро опубликовать на Netlify

1. Распакуйте архив.
2. Зайдите в Netlify.
3. Найдите вариант ручной загрузки сайта / Deploy manually / Drag and drop.
4. Перетащите всю папку `wedding_site_placeholder`, не отдельные файлы.
5. Netlify выдаст временный адрес вида `something.netlify.app`.
6. Проверьте сайт на телефоне.
7. Потом в настройках Netlify можно подключить домен `misha-polina-2026.ru`.

## Что менять позже

- Дату, место и тайминг — в `index.html`.
- Цвета — в начале `style.css`, блок `:root`.
- RSVP-ссылку — в `index.html`, секция `id="rsvp"`.
