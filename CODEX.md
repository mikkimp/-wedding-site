# Инструкция для Codex

## Проект

Это статичный сайт-приглашение на свадьбу Миши и Полины.

Домен: `misha-polina-2026.ru`
Хостинг: Netlify
Репозиторий: `mikkimp/-wedding-site`

## Текущая структура

- `index.html` — разметка страницы и тексты.
- `style.css` — визуальный стиль, цвета, адаптивная версия.
- `script.js` — мобильное меню.
- `assets/` — будущие изображения, иконки, аудио и другие медиа.

## Как работать с проектом

Проект пока не использует сборщик, фреймворк или npm-зависимости. Это обычный HTML/CSS/JS-сайт.

Для локального просмотра достаточно открыть `index.html` в браузере. Если браузер блокирует какие-то локальные ресурсы, можно запустить простой локальный сервер:

```bash
python3 -m http.server 8000
```

Потом открыть:

```text
http://localhost:8000
```

## Netlify

Netlify должен публиковать сайт из корня репозитория.

Build settings:

```text
Branch: main
Base directory: пусто
Build command: пусто
Publish directory: .
```

После каждого commit/push в ветку `main` Netlify должен автоматически обновлять сайт.

## Правила правок

1. Не добавлять тяжёлые зависимости без необходимости.
2. Сохранять адаптивность под телефон — сайт в первую очередь будут открывать с QR-кода.
3. Не менять финальный URL без отдельного решения.
4. RSVP-кнопку позже заменить на реальную ссылку Google Forms / Яндекс Формы.
5. Для будущей игры использовать отдельную папку `game/`, чтобы адрес был вида `/game/`.
6. Сохранять русский текст в UTF-8.
7. При правке текстов проверять букву `ё`: «всё», «ещё», «тёплый», «Серёжа» и т. п.
